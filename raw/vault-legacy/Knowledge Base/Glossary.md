# Tartarus Glossary

## Deception & Honeypots

| Term | Definition |
|------|-----------|
| **Honeypot** | Decoy system designed to attract and monitor attackers |
| **Beelzebub** | LLM-powered honeypot framework (Go) — generates realistic responses |
| **Deception** | Active defense strategy using fake assets to detect intrusions |
| **Trap** | An exposed service endpoint (SSH, HTTP) designed to capture attacker behavior |

## Attack Patterns

| Term | Definition |
|------|-----------|
| **Brute-force** | Repeated authentication attempts with different credentials |
| **Lateral movement** | Attacker pivoting from one compromised system to another |
| **Credential stuffing** | Using leaked username/password pairs across services |
| **Reverse shell** | Attacker-initiated connection from compromised host back to C2 |

## Infrastructure

| Term | Definition |
|------|-----------|
| **RabbitMQ** | Message broker for async event processing (AMQP protocol) |
| **asyncpg** | PostgreSQL async driver for Python |
| **aio-pika** | RabbitMQ async client for Python |
| **CIDR** | Classless Inter-Domain Routing — network range notation (e.g., 192.168.1.0/24) |

## Intelligence

| Term | Definition |
|------|-----------|
| **Shodan** | Search engine for internet-connected devices |
| **GeoIP** | Geographic location lookup by IP address |
| **ASN** | Autonomous System Number — identifies network operators |
| **MITRE ATT&CK** | Framework of adversary tactics and techniques |
